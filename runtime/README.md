# HCunion runtime

This folder contains only the Minecraft 1.8.8 WASM-GC bootstrap loader and its launch page.

There are no HCunion-added mods, mod menus, module controls, combat automation, macros, or practice overlays in this repository.

The game package is loaded from the upstream Minecraft-Launcher repository at runtime. If an in-game menu or feature still appears, it may be part of that external game package or stale browser data; it is not a mod file in this HCunion repository.

The game runtime has not yet been independently verified in-browser.
